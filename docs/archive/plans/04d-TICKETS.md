# 04d — Sales & CRM: build tickets (section 12 of 04-SALES-CRM.md)

Read `00-BUILDER-RULES.md` (rules, report format), `01-SHARED-FOUNDATION.md`, `03c-SCM-TICKETS.md` (the recipe H1-H5 and the helpers this plan reuses), and the section of `04a`/`04b`/`04c` a ticket names. One ticket = one builder session. Order is strict: a ticket may only use what earlier tickets built. Paths are under `apps/api/src/` unless they start with `apps/api/`, `apps/web/` or `tests/`.

## 12. Build tickets

### 12.0 Common recipe (referenced as H1-H6; every page ticket follows it)
* **H1 Definition.** `modules/crm/definitions/<page>.ts` or `modules/sales/definitions/<page>.ts` exports `<PAGE>_SCHEMA: SalesTypedSchema` built with `defineSales()` and the helpers of `modules/sales/definitions/common.ts` (T-SAL-06: copies of `f, money, qty, text, select, date, refLookup, statusField, action` from `modules/scm/definitions/common.ts`). Fields in the frozen order of `04a` with frozen labels, **keys exactly as the `key` column of `04a`**, types and required marks exactly as `apps/api/tests/fixtures/field-types.json`; `[ADD]` fields after them; `listColumns` = first 11 frozen keys + `status` (plan 03 C3); `actions` = the rows of `04c` §7.4 (`key,label,variant,confirm,allowedFrom,requires,requiresFrom?`); `filters`, `totals`, `statuses`, `editableStatuses`, `tabs` (the 6 frozen labels), `tabPanels` (from `04c` §7.9).
* **H2 Repository.** `<area>/repository.ts` is the only file that touches Prisma/SQL. Every read applies: unit filter (context unit; all units only for ADMIN+), `deleted_at is null`, and `salesScopeWhere(caller, pageId)` (BR-SAL-60). Locks use `SELECT … FOR UPDATE` inside the transaction before reading the values to change.
* **H3 Service.** `<area>/service.ts` exports `const <area>Handler: TypedHandler` (`list, get, create, update, remove, restore, action, exportRows`), uses `modules/scm/shared/doc.ts` (`requireUnit, loadFy, assertFyOpen, assertDateInFy, nextDocNumber, runDocAction`), `shared/row.ts::toRow`, `shared/links.ts`, audit through `writeSalesAudit(db, caller, action, target, row, pageId, detail)` (T-SAL-06), `TimelineService.add` where `04a` says so. Money only with `Decimal`.
* **H4 Register.** Add the handler to `modules/sales/typed-pages.ts` (T-SAL-06) and the page id to `TYPED_PAGES` in `engine/kinds.ts` **in the page ticket** (and remove `crm-pipeline` from `CUSTOM_PAGES` in its ticket).
* **H5 Tests** `apps/api/tests/sales-<area>.test.ts` with `tests/sales-helpers.ts` (T-SAL-06): create; list filters and totals; get; PATCH with `If-Match`; Draft-only edit/delete (`RECORD_LOCKED`); every action allowed and forbidden by status (`CONFLICT`); permission (`FORBIDDEN`); unit and FY (`CONTEXT_INVALID`, `PERIOD_CLOSED`); data scope (404 outside scope); audit rows; idempotent replay (two calls, one audit row); number format and gap-free numbering; the BR examples with the numbers of `04c`.
* **H6 Frozen-field test.** `tests/sales-schema.test.ts` (T-SAL-06, extended by every page ticket) compares, for each registered page, label, type and required mark of the frozen fields with the fixture, and `tabs` with the registry.
* **Size labels.** S ≤ 4 files, M ≤ 8, L ≤ 12 files and about 900 lines. Every new source file starts with a 1-3 line "why this file exists" comment. Test helpers delete only the rows they created.
