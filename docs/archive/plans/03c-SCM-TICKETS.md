Canonical example: `apps/api/src/modules/inventory/vouchers/service.ts` (`runAction`, create/update/remove/restore, FY checks, numbering, audit, idempotency) and `inventory/definitions.ts` + `typed.ts`.
* **H1 Definition** `modules/scm/definitions/<page>.ts` exports `<PAGE>_SCHEMA: ScmTypedSchema` (type defined in T-SCM-05) built with the helpers of `definitions/common.ts` (`f`, `money`, `qty`, `text`, `select`, `date`, `refLookup`, `statusField`, `action`). * **H2 Repository** `modules/scm/<area>/repository.ts`: the only file with Prisma/SQL: `list(filters, page)`, `findById(db,id)`, `lockById(tx,id)` (`SELECT … FOR UPDATE`), `insert`, `update` (with `version` check: `WHERE id=$1 AND version=$2`, `RETURNING`; zero rows → `Errors.versionConflict()`), `replaceLines(tx, docId, lines)` (delete+insert for Draft only), `softDelete`, `restore`, helpers for counters.
* **H3 Service** `modules/scm/<area>/service.ts` exports `const <area>Handler: TypedHandler` (interface in `inventory/typed.ts`): `list, get, create, update, remove, restore, action, exportRows`. Use the shared helpers of T-SCM-05 `shared/doc.ts`: `requireUnit(caller)`, `loadFy(tx, fyId)`, `assertFyOpen`, `assertDateInFy`, `nextDocNumber(tx, key, unitId, fyId)`, `scopeWhere(caller, pageId)`, `runDocAction(...)` (idempotency + lock + status check + audit), `toRow(...)`.
* **H4 Register** the handler in `modules/scm/typed-pages.ts` and the page id in `engine/kinds.ts` (done once, in T-SCM-05, for all 11 ids; the handler map entry is added by each page ticket).
* **H5 Tests** `apps/api/tests/scm-<area>.test.ts` using `scm-helpers.ts` (T-SCM-05 creates it, later tickets extend it): create, list filters/totals, get with lines, patch with `If-Match`, Draft-only edit/delete (`RECORD_LOCKED`), every action's allowed/forbidden status (`CONFLICT`), permission (`FORBIDDEN`), unit/FY (`CONTEXT_INVALID`, `PERIOD_CLOSED`), audit rows, idempotent replay, number format and gap-free numbering.
* **Status machine:** implemented as a `const TRANSITIONS: Record<action, {from: string[]; to: string}>` table in the service and checked inside the transaction after the row lock.
